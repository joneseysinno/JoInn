# S1 · Assay hand-test

**Can kill Phase 4.**

## Setup

The calculator body is a 2-complex whose 0-blocks are cells (and the host), whose 1-blocks are wires, and whose 2-blocks are laws that fill cycles.

Incidence table: `joinn/spikes/s1-assay/complex.txt`.

Vertices: `host`, `cli_a`, `cli_b`, `sum`.

Edges (oriented tail → head):

| edge | tail | head |
|---|---|---|
| e0 | host | cli_a |
| e1 | cli_a | sum |
| e2 | sum | host |
| e3 | host | cli_b |
| e4 | cli_b | sum |

2-blocks:

| face | filling | boundary (oriented) |
|---|---|---|
| f0 | `parse(format n) = n` at `cli_a` | `e0 + e1 + e2` = `host → cli_a → sum → host` |
| f1 | `parse(format n) = n` at `cli_b` | `e3 + e4 + e2` = `host → cli_b → sum → host` |

∂₁(e) = head − tail. ∂₂(f0) = e0 + e1 + e2. Then ∂₁∂₂(f0) = (cli_a − host) + (sum − cli_a) + (host − sum) = 0. Same for f1. No orientation tricks, no basepoints.

## Result

With both fillings present: H₀ = ⟨host⟩, H₁ = 0, H₂ = 0.

With f0 deleted: H₁ = 1, generated by the cycle `host → cli_a → sum → host` (edges e0 + e1 + e2).

The script prints the generator as named vertices, not a rank.

## Kill criterion

Not fired. Phase 4 remains in the plan.

## Negative note

The complex is small: two independent 3-cycles sharing the return edge `sum → host`. That is exactly the "shallow complexes" cost in Part III §14. The finding that decides Phase 4 is real at this scale; it does not prove the assay will earn its keep on deeper bodies.
