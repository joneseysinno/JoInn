## Gaps G1–G7

**G1 · ports.** Identity is `(direction, frame, position)`. Display names are regulatory. A removed position is a tombstone in `retired` and is hashed, because the promise "this position will never mean anything else" is identity.

**G2 · witnesses.** Founding witnesses are hashed and replayed exhaustively. Accumulated testimony lives in `TestimonyStore`, is never hashed, and is replayed under a budget. Recording a correct use does not move the cell hash.

**G3 · frame obligations.** A frame supplies values, equality, canonical form, generators, printer/parser, shrink, and — for an extension — embedding ι and restriction ρ. Phase 1 adds: ι is a signature homomorphism (zero, succ, pred, eq preserved).

**G4 · determinism.** DECIDED. No wall clock, no unseeded RNG, no `HashMap` iteration on any path that can reach a hash, a canonical form, a sample, or a refusal. Sampling takes a seed; a refusal carries that seed.

**G5 · join.** Declared on the contract, hashed, default `refuse`. Unread until Phase 2.

**G6 · refusal locality.** A `Refused` verdict does not cross a body boundary. No Phase 1 consequence; the type is not designed to be serialized across a membrane.

**G7 · the ease gate.** Scheduled from Phase 9. Phase 1 starts collecting concept-count evidence via `cargo xtask vocab` and the mutant corpus.
