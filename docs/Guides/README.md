# JoInn guides — start here

These pages are written in everyday language. You do **not** need to be a programmer to follow them.

JoInn’s deeper papers (Theory, Plans, Findings) stay as they are for the build work. Come back here whenever something feels cloudy.

## Five-minute picture

JoInn is meant to be a **visual app creator**: you snap small building blocks together to make real apps.

Those blocks are checked for **truth** (do they really do what they claim?) before the project spends years on a pretty screen. Today you can already run a small **calculator** demo in the terminal. A full visual editor comes later.
